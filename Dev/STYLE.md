# PickupGroup — UI style notes

Suite-wide rules (colour tokens, controls, accessibility, words, chat) live in
the "Suite style guide" doc in the WoW Addons project. Tokens are in
`Kit.Palette` (`soft`, `muted`, `warn`, `bad`, `brand`, rings and fills).

PickupGroup specifics:
- Lives inside Blizzard's Group Finder; the sidecar docks to its right edge and
  opens with the search pane.
- Blizzard's difficulty colours, friend blue and guild green pass through.
- Jokes only in the sign-up history and `/pug stats` (never the search pane).
- Accepted exception: apply-as role icons 17px apart.
